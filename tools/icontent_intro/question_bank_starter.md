# MooTyper Intro Question Bank Starter

Use these in fixed locations to keep all demo courses consistent.

## Slot A (Page 3): Readiness check

### Short

- I can access the target keyboard on this device. (Yes/No)
- I can open Lesson 1 and submit an attempt. (Yes/No)

### Medium

- What is your current confidence level with the keyboard layout? (1-5)
- What setup issue, if any, might slow your first attempt?

### Teacher-facing

- Which setup barrier appears most often in this group?
- Which learner needs an early keyboard walkthrough?

## Slot B (Page 5): Learning intent check

### Short

- In one sentence, why does typing practice help language learning?

### Medium

- Name one way accuracy feedback can improve writing confidence.
- Which is more important first in this course: speed or accuracy? Why?

### Teacher-facing

- Which responses show misunderstanding of course goals?
- What should be reinforced before graded practice begins?

## Slot C (Page 7): Instructor feedback capture

### Short

- What part of this intro should be clearer before students start?

### Medium

- Which page needs revision for clearer instructions and why?
- What extra example would improve student readiness?

### Teacher-facing

- Which wording should be adjusted for this audience or grade band?
- What local context should be added to improve adoption?
